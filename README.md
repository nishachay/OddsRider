# OddsRider

**Ride the odds.** Real Polymarket probability charts turned into rideable glowing terrain.

Dark cyber dirt bike. Toxic-green climbs, crimson drops. The market's collective belief, rendered as a track.

## Stack

Vite · React 19 · TypeScript · Tailwind CSS 4 · Phaser 3 (matter-js)

## Status

Phase 1 — core ride loop foundation: controllable Dark Cyber Dirt Bike on flat test ground.

## Commands

```bash
pnpm install
pnpm dev      # local dev server
pnpm build    # typecheck + production build
pnpm preview  # serve the production build
```

## Controls

| Key        | Action        |
| ---------- | ------------- |
| W / ↑      | Gas           |
| S / ↓      | Brake         |
| A / ←      | Lean back     |
| D / →      | Lean forward  |
| Space      | Jump          |
| Shift / N  | Nitro         |
| R          | Reset         |
| M          | Mute          |
